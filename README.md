# Elite Home Staging Website

A professional, responsive website for a home staging company built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **5 Pages**:
  - Home - Hero section with features and call-to-action
  - About - Company story, mission, and team members
  - Services - Detailed service offerings and process
  - Portfolio - Gallery showcase with testimonials
  - Contact - Contact form and business information
- **Interactive Elements**:
  - Mobile-friendly hamburger menu
  - Smooth scrolling
  - Form validation
  - Scroll animations
  - Hover effects

## Structure

```
staging-website/
├── index.html          # Home page
├── about.html          # About page
├── services.html       # Services page
├── portfolio.html      # Portfolio page
├── contact.html        # Contact page
├── css/
│   └── style.css       # All styles
├── js/
│   └── script.js       # Interactive features
└── images/             # Placeholder for images
```

## How to Use

1. Open `index.html` in a web browser to view the website
2. All pages are linked through the navigation menu
3. The contact form currently shows an alert - connect it to your backend/email service
4. Replace placeholder content with your actual business information
5. Add your own images to the `/images` folder and update references

## Customization

- **Colors**: Edit the color scheme in `css/style.css` (search for `#2c5f7f` and `#4a8fb0`)
- **Content**: Update text in each HTML file
- **Images**: Add images to `/images/` folder and update gallery items
- **Contact Info**: Update email, phone, and address in footer and contact page

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge)
